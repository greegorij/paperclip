## Symptom

Jarvis provider profile-switch apply PATCHes an agent successfully, then
post-PATCH verification fails with `desiredSkills drift during profile patch`
even though skills were not touched by the profile switch. Automatic rollback
runs; the fleet stays on the previous provider profile.

## Proven root cause

`verifyPatchedAgent` read `desiredSkills` from `GET /api/agents/:id`.

That agent detail endpoint **does not return** `desiredSkills`. The verifier
coerced a missing field to `[]` and compared it to
`expectedStep.from.desiredSkills` (typically a non-empty list from the live
fleet snapshot, which itself loads skills via
`GET /api/agents/:id/skills`). Non-empty vs `[]` always looked like drift.

True assignment state is available on `GET /api/agents/:id/skills` as
`desiredSkills` (see fleet `snapshot.mjs`). The drift gate itself was correct;
the read path was wrong.

## Repair

1. After verifying status / adapterType / adapterConfig / runtimeConfig from
   agent GET, fetch `GET /api/agents/:id/skills`.
2. Treat skills GET HTTP failure **or** a missing/non-array `desiredSkills` as
   a hard verification failure (fail-closed).
3. Compare the skills response array exactly to
   `expectedStep.from.desiredSkills` — keep the drift gate.
4. Regression tests:
   - agent GET omits `desiredSkills`, skills GET returns the preserved
     non-empty list → apply + verify succeed;
   - skills GET returns a drifted list → fail + rollback;
   - skills GET omits the `desiredSkills` array → fail + rollback.

## Prevention

- Do not treat absence of a field on agent GET as “empty skills”; use the
  skills endpoint (same contract as snapshot).
- Keep a mock that can omit `desiredSkills` on agent GET so the false-positive
  path cannot regress silently.
- Prefer fail-closed on skills verify transport/shape errors over coercing to
  `[]`.

## Resolution

- `verifyPatchedAgent` now loads desired skills from `/skills`.
- Focused profile-switch suite covers the production shape and negative cases.
- Drift gate remains; only the data source changed.
