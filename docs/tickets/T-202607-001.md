## Source of the problem

Live Jarvis fleet (29 agents) carried **instruction/skill contradictions** against role contracts:

1. Shared “create branch / edit / commit” block present on read-only or non-edit roles (Recenzent, Zwiadowca Kodu, Inżynier Wdrożeń) and on Senior Programista (who must delegate coding).
2. Mięsień Web / Mięsień Recenzji GLM used `in_review` for supervisor-agent verification instead of human decision waits.
3. Skill sets on four roles included `commit`/`release` (and extras) that contradicted the contract.
4. Mięsień Vault model alias `haiku` needed normalization to `claude-haiku-4-5`.
5. Summarizer (managed built-in) documentation/claim implied default `cheap` profile lane while expected live model is direct `claude-haiku-4-5`.

## Evidence

- Secret-free portable export of 27 agents (`paperclip-fleet-export-20260729-1243.json`) with platform warning: skipped 2 built-ins.
- Instruction sections `GDZIE WOLNO PISAĆ KOD` with `git checkout -b` / edit / commit on roles that forbid editing.
- Frontmatter skill lists including `commit`/`release` on Inżynier Wdrożeń and Senior Programista; Web/GLM skill bloat vs contract.
- Platform skill snapshot shape: `entries.length ≈ 39` is the **catalog**, not assignment.

## False positive — 39 catalog entries

`GET /agents/:id/skills` returning ~39 entries does **not** mean 39 skills are injected into the agent.

Correct interpretation:

- `desired` / `desiredSkills` = assignment intent (1–10 or 1–5 by adapter).
- Active runtime state = `configured` (claude/codex) or `installed` (cursor/opencode) for those desired skills only.
- Remaining catalog rows should be `available` (or otherwise non-active).

Treating `entries.length === 39` as misconfiguration would have caused destructive skill stripping. Tests in `ops/fleet/jarvis/tests/` lock both the healthy and unhealthy shapes.

| Misreading 39 skill catalog entries as assignment | Yes — document adapter skill states next to any fleet audit |

## Prevention

1. Keep fleet desired state versioned under `ops/fleet/jarvis/desired/` and run `validate` in CI/agent checks for this fork.
2. Never “fix” skills from catalog length alone.
3. Contradiction detectors (`desired/contradictions.json`) gate package edits.
4. Built-ins stay out of portable import; document endpoint/reset remediation only.
5. Never accept soft backup confirms; never apply without write-verify GETs.
