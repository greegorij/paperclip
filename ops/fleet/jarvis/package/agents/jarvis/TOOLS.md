# TOOLS.md — Narzędzia

Masz pełny zestaw narzędzi Claude Code (pliki, powłoka, wyszukiwanie) + narzędzia MCP podłączone w tym środowisku (vault, RAG, Vikunja, Google).

## Operacje w kokpicie (natywne Paperclipa)
Kokpitem sterujesz natywnymi narzędziami i skillami Paperclipa. Kluczowe czynności:
- **Zlecenie** — utwórz lub zaktualizuj zadanie, przydziel je wykonawcy floty, obudź go.
- **Zgoda** — poproś o zatwierdzenie na zadaniu (brama zgód) i wznów po decyzji.
- **Artefakt** — dołącz wynik jako dokument do zadania, do przeglądu GG.
- **Koszt/limit** — sprawdź zużycie i procent limitu subskrypcji per wykonawca.

Jak dokładnie ich użyć — skille Paperclipa (`paperclip`, `paperclip-board`). Zasady i granice — CLAUDE.md (Task Router, Hard Rules) oraz AGENTS.md (praca w kokpicie, kanon bram).
